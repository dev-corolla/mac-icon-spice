I called my Dock a grayscale graveyard. So I built Icon Spice 🌶️

Colorful Mac icons. Preview, apply, restore.

Open source. Early build.
https://github.com/dev-corolla/mac-icon-spice

## Optional follow-up

Default generation runs locally. AI customization is optional: ask for crisp logos, a specific color, subtle gradients, or less glow.

You preview everything before applying, and your previous icons are saved for restore.

Build instructions are in the README.

## Availability

The public repository contains the native app, CLI, tests, packaging scripts, and this video’s source. This announcement introduces an early source build. A notarized binary download has not been published.
